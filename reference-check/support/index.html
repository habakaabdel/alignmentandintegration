Reference Check, support

Help with Reference Check

Reference Check is a plugin for ChatGPT published by Alignment Integration. You paste a reference list, and it checks each reference against Crossref and tells you which ones match, which ones differ, and which ones are not in Crossref.

How to reach us

Write to alignmentandintegration@gmail.com. It helps to include the reference you checked, exactly as you pasted it, and the result you got.

How to use it

In ChatGPT, paste your reference list and ask for it to be checked with Reference Check. Up to 25 references are checked at a time. Keep the DOIs in if you have them, because a DOI gives the most reliable check.

Common questions

  • A real reference came back as not found in Crossref. Not found means Crossref holds no record of it, not that it is not real. Books, reports, theses and DOIs registered with other agencies, such as DataCite, are outside Crossref.
  • A reference came back as a mismatch. The Crossref record is shown beside it. Compare the DOI, title, first author and year, and correct whichever is wrong in your list.
  • A reference came back as could not check. Crossref did not answer in time. Try that reference again.
  • Does it write or fix references for me? No. It only checks references against Crossref and shows you the record it found.
  • Does it keep my references? No. Nothing is stored. The privacy notice has the detail.

sample deliverable

Indicator Map for a community mental health and addictions agency

Every number the agency reports to Ontario Health, defined once, traced to the data elements it is built from, and checked against the move from PDS 1.0 to PDS 2.0. Nothing on this page is agency data. It is built only from Ontario Health's public PDS documents.

Draft · awaiting agency sign-off

Ontario Health provider metrics

A decision for the agency

Indigenous identity. Under PDS 1.0, records with an Indigenous identity were not submitted to Ontario Health and are filtered out of every metric above. PDS 2.0 lists Indigenous Identity as element 1.2.16. Before anything is mapped, a First Nations agency decides, under its own data governance, whether and how this element is collected and sent. The map records that decision and who made it.

How the map gets built

Week 1Draft from the documents

Each metric's definition and calculation comes from Ontario Health's dictionaries. Each element is matched across PDS versions and flagged when the match is uncertain.

Week 1 to 2Map to the agency's system

Each element is tied to the field where staff enter it in the client record, with the program and functional centre codes checked by the people who run those programs.

Week 2Approve, then cite

The agency's data lead signs off each indicator. From then on, every report names the map entry it was counted from.

Sources, all public on Ontario Health's MHA PDS Resource Hub

  1. Provider Reports & Metrics, MHA-PDS, January 2024 (file dated 22 November 2024). Definitions and calculations for all twelve metrics, with PDS 1.0 element codes.
  2. Data Dictionary page, version 105, updated 21 September 2026. The PDS 2.0 element list used for matching.
  3. Mapping & Data Transformation (PDS 1.0 to PDS 2.0), updated 23 June 2026. Requires mapping sign-off with clinical and technical approval.

Matches between PDS 1.0 codes and PDS 2.0 elements are by element name. They are confirmed against Ontario Health's Logical Data Dictionary before sign-off. MHA PDS Resource Hub
